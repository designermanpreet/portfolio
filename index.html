Step 01 🔍
Understand First

I start by deeply understanding the problem space — user interviews, data analysis, competitor mapping. No assumptions, only evidence.

Step 02 ✏️
Think in Systems

Good design solves today's problem and tomorrow's edge case. I map flows holistically before touching pixels, spotting conflicts early.

Step 03 ⚡
Iterate Fast

Rapid prototyping, quick feedback loops, real user testing. I'd rather learn from a low-fidelity test than a polished Figma file nobody's seen.

Step 04 🤝
Ship Together

Design doesn't end at handoff. I embed with engineering through development, sweating the details that make the difference between okay and excellent.
